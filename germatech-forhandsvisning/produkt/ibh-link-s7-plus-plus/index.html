Beskrivning

IBH Link S7++ för kommunikation mellan PC och S7-200®, S7-300® eller S7-400® är ett kostnadseffektivt alternativ till vanliga PC-PLC-anslutningar.

IBH Link S7++ är en ultrakompakt och robust Ethernet-Konverter i en D-Sub-kapsling för anslutning via en switch, en hub eller även direkt till PC med ett vanligt nätverkskort.

Protokoll är det vanliga standard-TCP/IP. Alla fördelar med Ethernet kan därmed utnyttjas, t.ex. fjärrdiagnos via standard router eller VPN-anslutningar (Virtual Private Network).

Likaså är en direkt anslutning till Internet möjlig.

Avsedd för S7-200®, S7-300® eller S7-400®.

IBH Link S7++ kan användas såväl på PROFIBUS DP med upp till 12 MBit/s som på PPI® och MPI®. Detta leder till en betydande kostnadsreduktion, då varken SimaticNet® eller en CP-Kommunikationsprocessor erfordras, varken på PC-sidan eller PLC-sidan. IBH Link S7 ++ ersätter IBH Link S7 och IBH Link S7 CrossOver, och erbjuder följande funktioner:

  • CommDTM för FDT Container fritt tillgänglig
  • Masterklass 2 för asynchrona tjänster (DPV1)
  • Konfiguration via Webbläsare
  • Stöd för Windows7 64 Bit
  • Stöd för STEP®7 64 bit
  • PROFIBUS-diagostik
  • Slavdiagnostik
  • Konfiguration av slavparametrar via DPV1
  • Projektering av drifter
  • Integration i TIA-Portal
  • DHCP
  • Routing via RFC1006
  • PLC till PLC Kommunikation
  • Access till processdata från andra styrsystem, Windows och Linux
  • Support för STARTER, S7-PCT, PDM, LifeList., COM PROFIBUS
  • Projektering och diagnos av fältenheter via TCI
  • 16 samtidiga PC-förbindelser
  • 32 samtidiga MPI® / DP-förbindelser
  • Automatisk Baudrate-identifiering
  • RJ45-kontakt med autodetect
  • PG-Kontakt<br> - RFC1006
  • Diagnos LEDs
  • Spänningsförsörjning direkt från MPI® kontakten

Anslutning också till passiva enheter via integrerad 24V-anslutningsplint.

Med IBH Link S7++ kan styrsystemet programmeras via Ethernet på samma sätt som med en CP. Alla erforderliga drivrutiner för SIMATIC® S7, IBHSoftec Soft-PLC, STEP®7 från Siemens och S7 för Windows ingår i leveransen. Naturligvis fungerar IBH Link S7++ tillsammans med IBH OPC-Server.

Standard HMI-Applikationer kan kommunicera med IBH Link S7++ via RFC1006

Förutom programmeringsfunktionerna är även access från högnivåspråk via ett medlevererat API möjligt. Exempel i Windows för Visual Basic®, Visual C/C++®, VB.Net®, C#®, Delphi®, Java®, Excel® samt även för Linux medföljer.
