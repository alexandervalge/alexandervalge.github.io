Beskrivning

IBH Link UA är en OPC UA Server/Client modul.

För SIMATIC S5, S7-200, S7-300, S7-400, S7-1200, S7-1500 och Logo! (Ethernet Versionen) styrningar. Dessutom för Modbus, MQTT, Melsec och Rockwell styrningar. Det är en kompakt enhet för montering på DIN-skena

IBH Link UA Quad Core 64 bit Har samma funktionalitet som den tidigare IBH Link UA Quad Core men är betydligt kraftfullare, då den har en 64-bit 1.8 GHz processor som har 4GB RAM till förfogande.

(som jämförelse: IBH Link UA Quad Core 32 bit har en 32 bit 1 GHz processom och 2 GB RAM)

Dessutom ger IBH Link UA Quad Core möjligheten att utöka funktionaliteten med cloud services genom att använda ett SD-kort. Kontakta vär support för information om detta.

Egna IoT Edge-projekt kan realiseras i Docker-containers.

IBH Link UA konfigureras med den fritt tillgängliga IBH OPC UA Editor, original Siemens STEP7 eller med TIA Portal. Ingen speciell mjukvara måste installeras på programmerings-PC:n. Därmed är IBH Link UA sömlöst integrerad i PLC-projektet. Upp till 31 STEP7 och / eller TIA Projekt kan parallellt bearbetas av servern.

Variabeldefinitionerna överförs från programmeringsmjukvaran till IBH Link UA via Ethernet. Variabelattributen (t.ex. skrivskydd eller gränsvärden) definerar man direkt i PLC-projektet. Därmed är symbolisk access av datatstrukturer i datablock och variabler möjlig.

Kommunikation med styrningarna sker med TCP/IP. Om någon styrning saknar ethernetanslutning kan detta lösas med de beprövade kommunikationsadaptrarna IBH Link S7++ eller IBH Link S5++.

En fördel med IBHsoftecs lösning är att det är en Server-/Client version. Genom OPC-Client-funktionen är det också möjligt att utbyta data mellan OPC-servrar. Med denna funktion kan t.ex. data utbytas med styrningar eller anna utrustning med OPC UA från olika tillverkare. Konfiguration av Client funktionen görs i webbgränssnittet.

Användardefinerade OPC UA Variabler: I en egen namnrymd kan datastrukturer defineras som med Client-funktionen kan förbindas med valfri annan OPC UA server. På så sätt kan andra OPC UA Clients läsa och skriva dessa datastrukturer.

MQTT koppling: Här kan användardefinerade OPC UA variabler förbindas med en MQTT Broker/Server.

IBH Link UA kan därmed användas som ett lager mellan maskiner och överordnade system (MES, ERP…) oberoende av Simatic styrningar.

Medan OPC Data Access ger tillgång till data i realtid, stöder OPC Historical Access, även kallat OPC HDA, tillgång till historiska redan lagrade data. Från enklar dataloggningssystem till komplexa SCADA-system kan historiska data läsas på normerat sätt. Aktivering av denna funktion sker i webbgränssnittet.
