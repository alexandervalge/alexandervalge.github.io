Beskrivning

Många OPC-servrars handhavande betecknas som enkla. Ganska snart upptäcker dock användaren att det i praktiken inte är fullt så enkelt.

Även för oss är det ett känt faktum att automation inte alltid är så enkelt. Trots detta har vi lyckats skapa en server med vilken du med några få musklick är igång. Ett intuitivt gränssnitt leder dig genom konfigurationen. Den symboliska adresseringen i din programfil och i dina datablock kan direkt användas i din visualiering.

Välj med några få musklick de önskade variablerna från PLC-projektet, eller välj samtliga variabler.

Följande filformat för programfilen stödjs:

S5 für Windows®, S7 für Windows®, STEP®5, STEP®7, Extern källa (STL).

Kommunicera med alla SCADA-system:

Med IBH OPC Server ansluter du på enklaste sätt ditt SCADA-system till en Simatic® PLC eller en IBHsoftec SoftPLC. Exempelvis kan WinCC® från Siemens eller Intouch® från ICT Wonderware användas, för att bara nämna ett fåtal.

Följande kommunikationssätt är möjliga:

  • * S5-AS511
  • * S5-TCP/IP
  • * IBH-S5-SoftSPS
  • * S7-300/400 över Profibus/MPI med PC Adapter ( seriell / USB )
  • * IBH S7-CX317/CX416 över RFC1006 / IBH Net
  • * S7-200/300/400 över IBH Link
  • * IBH-S7-SoftPLC
  • * S7-TCP/IP direkt och över Ethernet

* S7-Online-gränssnittet (SIMATIC NET) kan också anropas direkt.

* Med en tillbehörsdriver är även kommunikation över S5-H1 och S7-H1 möjlig.
