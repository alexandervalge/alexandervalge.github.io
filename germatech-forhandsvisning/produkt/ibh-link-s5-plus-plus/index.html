Beskrivning

Kostnadseffektivt alternativ till andra PLC-PC-anslutningar över Ethernet.

Om en SIMATIC® S5 skall anslutas via nätverk till en PC, används traditionellt en CP-Kommunikationsprocessor.

Germatech/IBHsoftec har alternativet :

IBH Link S5++IBH Link S5++ är en kompakt och robust Ethernet-konverter i en 15 polig D-Sub-kapsling, för anslutning via en switch, en hub eller också direkt till PC med ett normalt nätverkskort.Som protokoll används standard -TCP/IP.

Alla fördelar med Ethernet kan därmed utnyttjas, som t.ex. fjärrdiagnos via standard router eller VPN-anslutningar (Virtual Private Network). Direktanslutning till Internet är också möjligt.

Alla erforderliga drivrutiner för STEP®5 mjukvaran från Siemens fr.o.m. Ver 7.16 och S5 för Windows® ingår. Naturligtvis fungerar IBH Link S5++ utmärkt tillsammans med IBH OPC Server.

Anslutning av S7-HMI-enheter via RFC1006.

Förutom programmeringsfunktionerna finns även ett API för högnivåspråk som möjliggör HMI-tillämpningar med IBH Link S5++ För Windows operativsystem finns exempel i språken Visual Basic® ,Visual C®, C++®, VB.net®, C#®, Delphi®, Java®, Excel® med i leveransen.
